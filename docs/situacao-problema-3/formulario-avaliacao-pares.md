# Ficha de avaliação por pares — Clima Sustentável

Use uma cópia desta ficha para cada pessoa que testar o sistema. São cinco fichas no total. Não apague os campos. Se não houver falha, escreva “Nenhuma” na seção correspondente. Prints de erro ficam colados no espaço indicado, ou anexados com o nome `ficha-0N-print-01.png` na pasta `docs/situacao-problema-3/prints/`.

Antes do teste, a API deve estar em http://localhost:8000 e o site em http://localhost:5173. O login do painel é `admin@climasustentavel.org` / `Admin@123`.
