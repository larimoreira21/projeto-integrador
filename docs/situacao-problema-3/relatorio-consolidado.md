# Relatório consolidado dos testes de pares — Clima Sustentável

**Projeto Integrador Transdisciplinar em Engenharia de Software II**

Este arquivo reúne as cinco fichas e a matriz de triagem. Ele é a base do PDF de envio. Cada ficha começa em branco. Quem testar preenche a sua. Não copie resultado de uma ficha para outra.

Critério de severidade, usado na matriz:

| Severidade | Quando usar |
| --- | --- |
| Alta | Impede um fluxo principal: não entra no painel, não calcula a pegada, não grava a inscrição ou a API não sobe. |
| Média | O fluxo termina, mas com dado errado, mensagem confusa ou passo que o roteiro pede e a tela não oferece. |
| Baixa | Texto, alinhamento ou sugestão que não impede o uso. |

Decisão: **corrigir** entra no changelog e no código; **adiar** fica registrado com o motivo; **descartar** quando a ficha descreve um comportamento que já é o previsto (por exemplo, visitante não cadastra ecoponto).
